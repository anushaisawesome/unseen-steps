# Submission files

- unseen-steps-technical-paper.pdf: problem, architecture, verification and tracking safeguards, evaluation, privacy, limits.
- unseen-steps-architecture.pdf / .png: the system on one page.
- unseen-steps-example-show-notes.pdf: what a studio gets back from its rehearsal (Andrii's waltz, from Atlas).
- unseen-steps-test-report.pdf: accessibility, the screen-reader test, the caption audit, the Atlas checks.
- unseen-steps-venue-screenreader-announcements.txt: the automated screen-reader test's log.

The demo video is on YouTube: https://youtu.be/4aadm47Nk1g. Its source file, the venue screen-reader test video and the submission slides are in the private clips repo, unseen-steps-clips/submission/ (they include other people's choreography and music, so they stay out of this public repo).
